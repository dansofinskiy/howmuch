# howmuch

Статическое SPA на русском для предварительного сравнения доставки в Грузию: Onex, Inex, USA2Georgia. Без зависимостей и сервера приложения. При открытии выполняется запрос курса USD/GEL к Frankfurter. Ссылки на товары не используются. Категория подставляет примерный вес и размеры одного товара с упаковкой; параметры можно уточнить вручную. Введённые данные существуют только в памяти вкладки.

## Запуск

`npm run dev` → http://localhost:5173

`npm test` — проверки расчётов. `npm run build` — статические файлы в `dist/`.

## GitHub Pages

Добавьте проект в GitHub-репозиторий с веткой `main`. В Settings → Pages выберите Source: GitHub Actions. Push в main запускает `.github/workflows/pages.yml`. Все пути относительные: приложение работает и по адресу /имя-репозитория/. Пока remote отсутствует, сайт не опубликован.

## Расчёт и ограничения

Страны: США, Великобритания, Германия, Китай, Турция, Греция. Валюта товара автоматически подставляется по стране: USD, GBP, EUR, CNY, TRY, EUR; её можно изменить вручную, включая GEL. Цена не конвертируется при смене страны — введите сумму в новой валюте. Курс автоматически загружается из https://api.frankfurter.dev/v2/rate/{CURRENCY}/GEL без ключа. Дата и источник показаны в форме. Frankfurter даёт справочный курс, не обязательно курс перевозчика или таможни. При ошибке незагруженный курс остаётся пустым; доступен ручной ввод и повтор загрузки. Таймаут 8 секунд, проверка ответа, предупреждение о данных старше 4 дней. Ответ не перезаписывает курс, введённый во время загрузки. Данные покупки сервису не отправляются. Тарифы также редактируются. Для Onex и Inex используется фактический вес, для USA2Georgia — max(фактический, Д×Ш×В/6000). Без размеров используется фактический вес с предупреждением. Нет автоматического округления или минимальной оплаты; это базовая оценка для обычных посылок, не точный счёт.

Итог = цена товара + доставка до склада + базовая международная перевозка + НДС + сбор таможни + оформление перевозчика + операционный сбор USA2Georgia + вручную введённые прочие расходы. Для одной обычной личной посылки НДС 18% начисляется при стоимости товара >300 GEL или фактическом весе >30 кг, на всю стоимость товара и перевозки (включая доставку до склада). Режим принудительного начисления позволяет оценить случай без льготы. Отдельный курс таможни применяется к порогу и налоговой базе; по умолчанию равен курсу оплаты. НДС округляется до тетри. Не рассчитываются товарная пошлина, акциз, незаданные сборы за оформление, страхование, негабарит и местная доставка. Прочие расходы общие для всех перевозчиков. Выгодность отмечается только по базовой перевозке.

Источники просмотрены 30.09.2026:
- Onex: https://www.onex.ge/ — 27 GEL/кг; правило веса: https://blog.onex.ge/welcome-to-onex-rus
- Inex: https://old.legacy.inex.ge/en/news/detail/128 — 9.7 USD/кг по таблице https://old.legacy.inex.ge/en/prices; новость от 04.06.2025 содержит 8.5 USD/кг, расхождение показано в интерфейсе.
- USA2Georgia: https://www.usa2georgia.com/packages — 9.95 USD/кг; объёмный вес: https://usa2georgia.com/agreements/en.html

Тарифы по умолчанию и формула: `calculator.js`. Это независимый калькулятор, не сервис перевозчиков.

Налоговые источники (30.09.2026):
- https://rs.ge/Media/Default/Images/CustomsBrochures/Exemption%20of%20goods%20from%20duties%20and%20declaring.pdf
- https://blog.onex.ge/customs
- https://www.rs.ge/CommodityCodes-en?cat=1&tab=1

Пример: товар 150 USD, 1 кг, курс оплаты и таможни 2.70, Onex 27 GEL/кг: товар 405 GEL, перевозка 27 GEL, НДС 77.76 GEL, сбор таможни 20 GEL, оформление Onex 15 GEL, итог 544.76 GEL без иных расходов.

Сборы при растаможке заданы по указанию пользователя: 20 GEL таможне для всех перевозчиков и 15 GEL за оформление Onex. Они редактируются, добавляются при taxable=true и не увеличивают базу НДС. Для Inex оформление интернет-посылки по умолчанию 10 GEL (с 01.07.2025), для USA2Georgia — 16 GEL за декларацию (п. 9.4 договора). Если поле очищено (null), интерфейс помечает итог неполным. Явный 0 означает отсутствие сбора. Заданные пользователем 20 GEL и 15 GEL не подтверждены как универсальные официальные тарифы. Государственный сбор для дорогих посылок может быть выше; поле редактируется.

Категории и условные оценки находятся в `app.js` (categories), не являются измерениями или данными магазина. По умолчанию кроссовки: 1.2 кг, 35×25×15 см. При смене категории ручные значения заменяются оценкой выбранной категории. «Другое» очищает значения и открывает ручной ввод.

Источники оформления, проверены 30.09.2026:
- Inex: https://old.legacy.inex.ge/ru/custom-procedures (для личных отправлений 15 GEL, для интернет-покупок 10 GEL).
- USA2Georgia: https://www.usa2georgia.com/agreements/en.html — п. 9.4, 16 GEL за декларацию; операционный сбор включён отдельно по п. 2¹.4.

Перевозка помечена знаком ≈ как предварительная оценка.

Операционный сбор USA2Georgia считается для каждой посылки независимо от растаможки, от стоимости товара по курсу оплаты; округляется до тетри и добавляется вне базы НДС. Ставки: <100 → 1 GEL; <200 → 2; <300 → 3; <3000 → 2%; <10000 → 4%; <20000 → 8%; ≥20000 → 12%. На пересекающихся границах договорных диапазонов выбран следующий диапазон, это допущение показано в интерфейсе. Например, $150 × 2.70 = 405 GEL → 8.10 GEL сбора.

## Направления

`routes.js` содержит тарифы, валюту, способ и правила веса по направлениям. Источники просмотрены 30.09.2026: https://www.onex.ge/ru, https://old.legacy.inex.ge/en/prices, https://www.usa2georgia.com/packages и договор USA2Georgia.

- США: Onex 27 GEL, Inex 9.7 USD, U2G 9.95 USD за кг.
- Великобритания: Onex 27 GEL, Inex 7.5 GBP за кг.
- Германия: Onex авиа 29 GEL, Inex наземная 8 EUR за кг.
- Китай авиа: Onex 35 GEL, U2G 12 USD за кг; наземная U2G 5.5 USD за кг.
- Турция: Inex и U2G 4 USD за кг.
- Греция: Inex и U2G 3.5 EUR за кг.

Inex Китай: опубликован тариф 12.5 USD для авиа, но формула объёмного веса не подтверждена, поэтому направление пока исключено из расчёта. Другие неподтверждённые направления не считаются и не изображаются бесплатными. Это не утверждение, что перевозчик не обслуживает страну.

Onex: стандартные посылки по фактическому весу согласно актуальной таблице; гиперобъёмные грузы не покрываются. Inex: фактический вес, минимум США/Турция 0.1 кг, Великобритания/Германия/Греция 0.2 кг. U2G: делитель 6000; США/Китай авиа — больший вес; Китай наземная — больший вес начиная с 30 кг фактического или объёмного; Турция — объёмный более 50 кг; Греция — фактический или объёмный более 50 кг.

Курсы запрашиваются для валюты покупки и валют тарифов независимо. Введённый таможенный курс относится к валюте товара, другие валюты доставки используют справочные курсы. При переключении страны сбрасываются тарифы и таможенный курс; устаревшие ответы предыдущего запроса игнорируются. Запрос, во время которого изменён курс вручную, не перезаписывает ввод.

## Сроки доставки

В карточках показаны приблизительные сроки по стране и типу перевозки (проверены 30.09.2026), с отдельными ссылками на источники. Это не дата получения с момента покупки. Onex: США/Великобритания 4–8 рабочих дней, Германия/Китай 5–10 рабочих дней с поступления на зарубежный склад (https://blog.onex.ge/welcome-to-onex-rus). Inex: США/Великобритания/Германия 5–10 дней, Турция/Греция 5–7 дней в пути; дополнительно ожидание рейса, таможня, сортировка 0–2 дня и распределение 0–3 дня (https://inex.ge/ka/shipment-information?lang=eng). USA2Georgia: США/Турция 7–10 рабочих дней, Китай авиа 5–8, Китай наземная 30–45, Греция 7–14 рабочих дней по карточкам тарифов (https://www.usa2georgia.com/packages). На странице U2G есть расхождения с общим описанием и договором; использованы значения карточек тарифов, они не гарантируют дату выдачи.

## Сравнение

Кнопка в карточке сохраняет независимый снимок параметров и результатов конкретного перевозчика в sessionStorage (`howmuch.comparison.v1`). В сравнении доступны разные страны и валюты, полная разбивка сумм, курсы и их даты, вес/размеры, категория, срок и время сохранения. Снимки не пересчитываются при изменении формы или загрузке новых курсов. Окно открывается кнопкой в шапке; варианты отсортированы по итогу, их можно удалить или очистить. При недоступном sessionStorage остаётся сравнение в памяти с предупреждением. Срок хранения — сессия вкладки, включая перезагрузку страницы.

Оплата разделена: сразу = товар + доставка до склада; потом = международная перевозка + НДС + таможенный сбор + оформление + операционный сбор + прочие расходы. Эти суммы сохраняются в сравнении; для старых снимков вычисляются из сохранённых сумм, без новых курсов. Разбивка — оценка этапов оплаты, а не график выставления счетов перевозчика.
